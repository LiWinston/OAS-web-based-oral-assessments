# OAS 口语评估 · 学生预约与场次管理

## 目的与范围
本文详细描述学生预约的生命周期与场次管理机制，覆盖 INDIVIDUAL（个人）、GROUP（小组）、MIX（混合）三种作业类型，以及时段到场次的生成逻辑、考官配岗流程与发布约束。

## 关键术语
- 预约（Booking）：学生为某作业在某场次的报名记录。
- 场次（Session）：从时段（TimeSlot）拆分生成的具体考试单元，带容量与时间段。
- 配岗（Staffing）：为场次分配考官（Examiner），受场次上限与人力限制约束。
- 发布（Release）：对考官/学生开放可见与操作的切换，学生发布需“完全配岗”。

## 流程与数据交互
1. 列出可预约场次：学生在已“发布到学生”的作业下，查看符合时间与容量的场次列表。
2. 创建预约：提交作业/场次标识，校验容量、重复预约与时间冲突，创建 `session_student` 记录并更新容量计数。
3. 改约与取消：允许在业务窗口期内改约或取消；如存在评分记录（assessment），限制取消以保护数据一致性。
4. 时段→场次生成：课程管理员按“时长+间隔”在时段窗口内生成 `slot_sessions`；支持复制考官并校验场次上限；已发布作业的场次配置不可变更（护栏）。
5. 配岗与发布：为每个场次分配 `session_examiners`；发布到考官仅切换可见；发布到学生必须确保所有场次“完全配岗”，否则拒绝发布。

## 相关表与实体
- `assignment`：作业配置与类型（individual/group/mixed）。
- `time_slot`：时段窗口（含时长与间隔）。
- `slot_sessions`：由时段生成的具体场次，含容量与时间。
- `session_student`：学生预约记录（含小组/个人适配逻辑）。
- `session_examiners`：场次与考官的配岗关系与上限校验。
- `venue`：场地与冲突检查。

## 约束与边界
- 护栏：已发布作业的场次/时段配置不可编辑，避免扰动考试安排。
- 完全配岗：发布到学生前必须所有场次均有足够考官；否则发布失败。
- 重复与冲突：同学生不可重复预约同作业；需进行时间与容量冲突校验。

## 相关实现（映射提示）
- 控制器：`StudentTimeSlotController`（学生端预约与变更）、`AdminTimeslotController`（场次配置与发布控制）。
- 服务：`StudentTimeSlotServiceImpl`（创建/改约/取消逻辑与容量计数）、`TimeSlotServiceImpl`（时段→场次生成、复制考官、冲突与上限校验）、`ScheduleServiceImpl`（发布与就绪检查）。
