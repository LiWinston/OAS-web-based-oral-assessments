# OAS 口语评估 · 学生成绩与反馈接口

## 目的与范围
基于 `StudentResultsController` 实现，描述学生端成绩总览与单作业详情接口的业务逻辑，包括参数约定、返回数据结构与缓存头（If-Modified-Since）的使用机制。

## 能力概览（接口叙述）
- 成绩列表：`GET /api/students/{studentId}/results`
  - 说明：列出该学生在当前学期（或指定学期）的作业与已发布成绩与反馈的总览数据。
  - 参数：
    - `status`（默认 `released`）：过滤显示已发布或其它状态的成绩数据。
    - `semester`（默认 `current`）：当前或指定学期范围。
    - `pageNum`（默认 1）与 `pageSize`（默认 20）：分页参数。
    - `sort`（默认 `date_desc`）：排序策略（如按发布时间倒序）。
    - `If-Modified-Since`（请求头，选填）：用于客户端缓存与条件获取，减少不必要数据传输。
  - 返回：`StudentResultOverviewDTO`（叙述为主，包含作业列表、发布状态、评分简述等）。

- 作业详情：`GET /api/students/{studentId}/assignments/{assignmentId}/result`
  - 说明：返回该学生在指定作业的详细成绩与反馈，支持条件获取。
  - 参数：
    - `If-Modified-Since`（请求头，选填）：用于客户端缓存与条件获取。
  - 返回：`StudentResultDetailDTO`（叙述为主，包含量规项得分、总分、反馈文本、发布时间等）。

## 相关实现（映射提示）
- 控制器：`StudentResultsController`（以上两个 GET 接口）。
- 服务：`StudentResultsService`（查询与整合学生已发布成绩与详情，应用缓存头语义）。

## 边界与约束
- 可见性：仅在成绩“发布到学生”后可见；未发布或草稿阶段不提供学生端详情。
- 缓存语义：服务端可结合 `If-Modified-Since` 控制返回与 304 逻辑（具体由服务层实现决定）。
