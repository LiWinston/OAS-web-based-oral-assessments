# Sprint

This folder contains the sprint documentation for the project.

## Folder Structure

| **Folder** | **Description** |
| --- | --- |
| Sprint 1 | Documentation for the first sprint |
| Sprint 2 | Documentation for the second sprint |

Each sprint folder contains:
- **Agile Ceremonies**: Documentation of sprint planning, review, and retrospective meetings
- **Discussing Collaboration Documents**: Project artifacts and collaboration documents created during the sprint
