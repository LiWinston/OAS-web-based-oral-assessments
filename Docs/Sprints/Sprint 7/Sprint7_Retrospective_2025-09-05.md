# Sprint 7 — Retrospective (5 Sep 2025)

## Reflection
**Went well**
- Early end-to-end demo uncovered real-world scheduling nuances (parallel venues, Zoom).
- Team collaborated quickly to map model changes.

**Didn’t go well**
- Several validations missing in UI → client found them live.
- FE sometimes followed screens instead of **user stories/ACs** → gaps in acceptance.
- CSV format/mapping not robust; re-use UX missing.

**Improvements**
- Treat **client demo feedback** as blocking bugs for next sprint.
- Strengthen **Definition of Done**: includes validations, release gating, and at least 1 QA pass.
- Anchor FE tasks to **explicit ACs**; update stories before coding.
- Add a **test checklist** per flow (Create → Staff → Sessions → Release → Book).
