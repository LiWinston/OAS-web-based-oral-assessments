# **OAS Project Timeline Schedule (Sem2)**

## **Phase 1: Complete Administrative Functionality (Weeks 3-5)**

### **Week 3: Backend Foundation and Core Integration**

The backend team will implement four critical epics to establish the system foundation. Epic 9 (Super Admin Management) will provide complete administrative oversight capabilities, while Epic 4 (Assessment Structure Configuration) will enable comprehensive course and assignment management. Epic 2 (User Account Management) will establish secure authentication and user lifecycle management, and Epic 1 (Data Import and Export) will provide essential CSV handling and Canvas integration capabilities.

The frontend team will focus on integrating all Epic 2 functionality to ensure complete user authentication workflows and partial Epic 9 functionality to enable Super Admin oversight capabilities. This integration will establish the core user management foundation necessary for subsequent administrative features.

The testing team will develop comprehensive test plan documentation covering all backend API endpoints and frontend integration scenarios. This documentation will establish testing protocols for the remainder of the project and ensure systematic validation of all implemented functionality. Complete testing of backend interfaces and frontend integration success will provide confidence in the system foundation.

### **Week 4: Advanced Backend Features and Administrative Interface Completion**

The backend team will implement Epic 5 (Booking and Scheduling) to provide complete scheduling infrastructure and Epic 3 (Assessment and Feedback) to enable examination management capabilities. These implementations will support the core user flow requirements for subsequent phases.

The frontend team will complete integration of all Epic 9 functionality to finalize Super Admin capabilities, implement Epic 4 course and assignment creation components to enable administrative workflow management, and develop Epic 5 time slot configuration interfaces to support scheduling operations. This comprehensive integration will provide complete administrative functionality from the user interface perspective.

### **Week 5: System Refinement and Results Management**

This week will focus on comprehensive bug resolution based on testing feedback from previous weeks, with particular emphasis on ensuring all administrative functionality operates seamlessly. The backend team must implement real-time change support to enable immediate system updates without deployment delays, addressing the integration challenges identified in earlier discussions.

The backend team will implement Epic 6 (Mark Management and Publication) to provide complete results processing capabilities. This implementation will support future marking and results workflows while maintaining focus on administrative functionality completion during this phase.

The testing team will conduct comprehensive validation of all administrative features and provide detailed feedback for immediate resolution. All administrative functionality must achieve production-ready status by the conclusion of this week.

## **Phase 2: Core User Flow MVP Implementation (Weeks 6-7)**

### **Week 6: Examiner Assignment and Schedule Management**

The focus will shift to implementing the first components of the target user flow, specifically enabling examiner participation in the scheduling process. The backend team will enhance Epic 3 implementation to support examiner authentication, schedule viewing, and self-assignment capabilities for available time slots.

The frontend team will develop examiner dashboard functionality with intuitive interfaces for viewing available time slots, understanding assignment requirements, and completing self-assignment processes. The interface must clearly display time slot details, venue information, and capacity constraints to support informed examiner decision-making.

Testing will focus on validating the examiner assignment workflow, ensuring proper integration with administrative time slot creation, and verifying capacity management and conflict prevention mechanisms operate correctly.

### **Week 7: Student Booking System and User Flow Completion**

The final component of the core user flow will be implemented through comprehensive student booking functionality. The backend team will complete Epic 5 student-focused features including group member identification, available time slot viewing, and both individual and group booking capabilities.

The frontend team will develop student dashboard interfaces that provide clear visibility of group membership information, available time slots with relevant details, and streamlined booking processes for both individual and group scenarios. The interface must handle group coordination requirements and provide clear confirmation of successful bookings.

Comprehensive end-to-end testing will validate the complete user flow from Course Admin assignment creation through rubric configuration, time slot setup, examiner assignment, and student enrollment. This testing will ensure the system provides a complete, demonstrable workflow ready for client presentation.

## **Phase 3: Extended Functionality and System Completion (Weeks 8-12)**

### **Week 8: Assessment Execution and Marking Interface**

Development will focus on enabling the actual assessment process through comprehensive marking functionality. The backend team will enhance Epic 3 marking capabilities to support rubric-based assessment, individual and group feedback provision, and comprehensive progress tracking throughout the marking process.

The frontend team will develop examiner marking interfaces that provide efficient, user-friendly workflows for conducting assessments according to established rubrics. The interface must minimize navigation requirements and support both individual and group assessment scenarios with appropriate feedback collection mechanisms.

### **Week 9: Results Processing and Student Access**

The results management workflow will be completed to enable comprehensive mark calculation, administrative review, and controlled release to students. The backend team will enhance Epic 6 functionality to support accurate mark aggregation, administrative oversight of results, and secure student access to performance information.

The frontend team will develop student results interfaces that provide clear presentation of marks, detailed feedback, and performance breakdowns according to rubric criteria. The interface must support both individual and group result presentation while maintaining appropriate privacy controls.

### **Week 10: Advanced Reporting and Administrative Tools**

System capabilities will be enhanced through advanced reporting functionality and administrative tools that support comprehensive assessment management. The backend team will implement sophisticated reporting features including examiner performance analysis, assessment trend identification, and comprehensive administrative oversight capabilities.

The frontend team will integrate advanced administrative reporting interfaces that provide actionable insights for assessment management and quality assurance. These tools will support continuous improvement of assessment processes and administrative decision-making.

### **Week 11: Notification Systems and Communication Enhancement**

Comprehensive communication functionality will be implemented to ensure all system participants receive appropriate notifications and updates throughout assessment processes. The backend team will complete Epic 7 implementation including booking confirmations, assessment reminders, and examiner notifications across all user roles.

The frontend team will integrate notification functionality seamlessly across all user interfaces, ensuring appropriate communication without overwhelming users. Security features and audit logging capabilities will be finalized to support institutional compliance requirements.

### **Week 12: Final Integration and Production Preparation**

The final week will focus on comprehensive system validation, performance optimization, and production readiness preparation. All teams will collaborate on integration testing, documentation completion, and demonstration preparation for final client presentation.

This timeline structure ensures systematic delivery of the required user flow MVP by week 7 while maintaining comprehensive administrative functionality and providing a clear path to complete system implementation. The approach balances immediate client demonstration needs with long-term system completeness requirements.
