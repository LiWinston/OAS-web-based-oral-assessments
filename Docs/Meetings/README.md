# Meetings

This folder contains the meeting minutes for the project.

## Folder Structure

| **Folder** | **Description** |
| --- | --- |
| Week 3 | Meeting minutes from the third week, including client, mentor, and team meetings |
| Week 4 | Meeting minutes from the fourth week, including mentor and team meetings |
| Week 5 | Meeting minutes from the fifth week, including mentor and team meetings |

Each week folder contains minutes from different types of meetings:
- Client meetings: Discussions with the project client
- Mentor meetings: Guidance sessions with the project mentor
- Team meetings: Internal team coordination and planning sessions
