Project Scope - Overview

The Oral Assessment System (OAS) will streamline the entire oral assessment lifecycle

Core Problem

Current practices for managing oral assessments are manual, fragmented, and inefficient

Vision

Create a unified platform to manage oral assessments from scheduling through to feedback delivery

Key Goals

  • Streamline scheduling and booking process
  • Support structured feedback with customizable rubrics
  • Automate mark aggregation
  • Enable seamless integration with Canvas
  • Enhance user experience with role-based interfaces

Stakeholders

Students, Examiners, and Administrators

Slide 3
University of Melbourne | OAS Project

Project Scope - In-Scope Features (1/2)

1. User Account Management

  • Creation and management of user accounts (students, examiners, administrators)
  • Secure authentication and role-based access control

2. Assessment Configuration

  • Setup of academic periods (year, semester, subject)
  • Creation of assignments with individual or group designations
  • Configuration of customizable marking rubrics with hierarchical criteria

3. Scheduling and Booking

  • Administrator definition of assessment time slots and venues
  • Student booking of assessment slots (individual or group)
  • Examiner self-assignment to assessment slots

Project Scope - In-Scope Features (2/2)

4. Assessment Execution

  • Interface for examiners to view their assessment schedule
  • Tools for recording individual and group feedback
  • Support for predefined comments to ensure consistent feedback
  • Capability to save draft assessments and submit final marks

5. Mark Management and Reporting

  • Calculation and aggregation of marks based on rubric components
  • Control over when results are visible to students
  • Student access to their marks and feedback after release
  • Import/Export Canvas compatible data format (csv)

6. Integration, Notifications & Security

  • Import/export of student and group data via CSV files
  • Email confirmations and reminders
  • Privacy policy agreement and audit logging

Project Scope - Out-of-Scope Items

The following items are explicitly excluded from the project scope:

1. Direct Integration with University Systems

  • No direct API integration with university student management systems
  • No single sign-on (SSO) integration with university authentication systems

2. Mobile Application Development

The system will be web-based with responsive design, but no dedicated mobile apps will be developed

3. Advanced Analytics and Reporting

While basic reporting will be included, advanced analytics and data visualization tools are out of scope

4. Automated Grading or AI-Assisted Assessment

The system will not include AI tools for automated assessment or grading assistance

5. Live Video Assessment Capabilities

The platform will not include built-in video conferencing for remote assessments

Key User Stories - Administrator

As an administrator, I want to:

  • Upload a CSV file containing students and group information so that I can import data automatically and easily
  • Create specific assignments linked to subjects, designating them as individual or group based so that the booking and marking process aligns with the assignment type
  • Create and manage fully customizable marking rubrics associated with specific assignments so that examiners can follow a standardized assessment approach
  • Define available time slots and venues/locations for oral assessments linked to specific assignments so that students have a structured schedule to book from
  • View and calculate total marks based on rubric components and algorithm so that the final grade is accurate

Critical Requirements

  • CSV import/export compatibility with Canvas
  • Flexible rubric creation with hierarchical criteria
  • Automated mark calculation and aggregation

High-Value Features

  • Error handling during data import/export
  • Ability to preview changes before updates
  • Control over result visibility timing

Key User Stories - Examiner

As an examiner, I want to:

  • See my assigned assessment schedule so that I know when and where to conduct assessments
  • Have a user-friendly marking interface with minimal page navigation so that I can focus on the assessment rather than the tool
  • Provide feedback for individual students and group components so that performance is assessed appropriately
  • Select from pre-defined comments when providing feedback so that I can give consistent feedback efficiently
  • Input marks for each criterion defined in the rubric (both group and individual criteria) so that I can record my evaluation
  • Assign myself to available time slots for assessments I am responsible for so that I can build my examination schedule

Critical Requirements

  • Intuitive marking interface with minimal clicks
  • Ability to save progress during marking
  • Clear distinction between individual and group assessment

High-Value Features

  • Pre-defined comment library
  • Assessment schedule reminders
  • Independent marking capability

Key User Stories - Student

As a student, I want to:

  • View the available time slots and venues specifically for my assigned oral assessment so that I can choose a suitable appointment
  • Book an assessment slot for myself (for individual assessments) so that I can secure my preferred time
  • See my group members so that I know who I am working with
  • Book one available time slot for the entire group (as any member) so that the group secures an assessment time efficiently
  • Reschedule my booking if needed (excluding 24 hours before the appointment) so that I can adjust for unexpected circumstances
  • View my final marks and any associated feedback after they have been released so that I can understand my performance

Critical Requirements

  • Clear visibility of available time slots
  • Group booking capabilities
  • Ability to view assessment results

High-Value Features

  • Email confirmations and reminders
  • Rescheduling capabilities with time restrictions
  • Mobile-responsive interface

API Discussion: Booking System Integration

We've evaluated several integration options for the booking system component:

Commercial SaaS APIs

Examples: Nylas, Cronofy

  • Robust, CRUD-enabled Calendar APIs
  • Enterprise features and SLAs
  • Pricing based on usage metrics

Considerations: Cost, third-party data hosting

Self-Hosted Open Source

Examples: Cal.com, Easy!Appointments

  • Comprehensive features including group bookings
  • Full data control through self-hosting
  • Requires technical expertise for maintenance

Considerations: Maintenance burden, licensing

Custom In-House Development

  • Maximum control and customization
  • Integration with existing university systems
  • Highest development cost and time investment

Considerations: Development resource availability, timeline

Slide 13
University of Melbourne | OAS Project

Our Booking System Recommendation

After thorough analysis of options, we have a clear recommendation:

Our Recommendation

Based on our analysis, we recommend implementing a custom solution based on Cal.com:

  • Cal.com offers both a paid hosted version and open-source code
  • To save costs and enable customization, we propose developing our own implementation based on Cal.com's open-source codebase
  • Cal.com's technology stack (React, PostgreSQL) aligns perfectly with our project's technology stack
  • This approach provides full control over data while leveraging an established booking system architecture

We can discuss implementation details and resource requirements during today's meeting

Key Benefits

  • Full data ownership and control
  • Customizable to university-specific needs
  • Cost-effective compared to SaaS options
